# 주간 동향 — 기사 선별 기준

매주 일요일 밤 예약 작업이 **이 파일을 먼저 읽고** 그 주 기사를 고릅니다.
기준을 바꾸고 싶으면 이 파일만 고치면 됩니다. 코드는 건드릴 필요 없습니다.

---

## 관심 분야

- 교육 운영 / HRD / 기업교육
- 컨소시엄 사업, 공동훈련센터, K-디지털 트레이닝 등 정부 직업훈련 사업
- 생성형 AI — 특히 **교육·HR에 실제로 적용된** 것
- 교육센터 운영이나 컨소시엄 제안에 도움이 될 정책·공고·시장 자료

## 우선순위 (위에서부터)

1. **마감이 있는 공고·지원사업** — 놓치면 손해나는 것. 있으면 무조건 1순위
2. **과정 설계·운영 기준을 바꾸는 정책 변화**
   (예: KDT 'AI 캠퍼스'가 기업 현업 프로젝트 30% 이상 편성을 의무화)
3. **제안서에 인용할 수 있는 수치·자료** — 출처와 조사 규모가 분명한 것
4. **읽으면 재미있고 시야가 넓어지는 것** — 해외 사례, 다른 기관의 시도

## 빼는 것

- **교육업체·솔루션업체가 자기 서비스 팔려고 쓴 콘텐츠 마케팅 글.**
  "2026년 트렌드 5가지" 류의 블로그 글은 대부분 여기 해당합니다.
  → 예외: 그 안에 **1차 출처가 분명한 설문 데이터나 통계**가 있으면,
    업체 글이 아니라 **그 데이터를 제목으로** 올립니다
- 지난주에 이미 넣은 것 (새로운 진전이 있을 때만 다시)
- 날짜가 확인 안 되거나 1~2주보다 오래된 것
- 제목만 자극적이고 알맹이는 기존 내용 재배열인 것
- 우리가 이미 다 아는 일반론 ("AI가 중요하다" 수준)

## 분량

- **4~6건.** 억지로 채우지 않습니다. 건질 게 3건이면 3건만 넣습니다
- 카카오톡으로는 **제목만** 나갑니다 (마커 줄 제외 190자 이하 = 1통)
- "왜 볼 만한지"와 원문 링크는 웹페이지에 둡니다

## 쓰는 방식

- 확인되지 않은 숫자·마감일을 지어내지 않습니다. 불확실하면 "확인 필요"라고 씁니다
- "왜 볼 만한지"는 기사 요약이 아니라 **우리한테 무슨 의미인지**를 씁니다
  (나쁜 예: "AI 교육이 확대된다고 한다")
  (좋은 예: "우리가 지원 대상에 해당하는지, 컨소시엄으로 들어갈 수 있는지 확인해볼 만함")
- 저장소가 공개(Public)이므로 링크와 공개 정보만 씁니다. 내부 정보는 절대 넣지 않습니다

## 타사 교육과정 조사 (`타사교육과정.csv`)

기사와 별개로, 매주 **타사가 지금 어떤 과정을 파는지**를 모아 표로 쌓습니다.

**이 표는 카카오톡으로 보내지 않습니다.** 쌓아두기만 하고, "타사 교육 리스트 줘" 하고 요청할 때만 꺼내 봅니다.
매주 알림에 밀어넣을 내용이 아니라, 필요할 때 찾아보는 자료입니다.

### 볼 대상

| 구분 | 예 |
|---|---|
| 기업교육(B2B) | 멀티캠퍼스, 패스트캠퍼스, 휴넷, 인프런, 코드잇, 엘리스 |
| 공공·협회 | 한국표준협회(KSA), 한국생산성본부(KPC), 능률협회(KMA) |
| 정부 훈련 | KDT·AI 캠퍼스 운영기관, 공동훈련센터 운영기관 |
| 대기업 사내 | 삼성 / SK mySUNI / LG / 현대 등의 사내 AI 교육 |
| 대학 | 서울대 SACTA 등 대학 부설 기업교육 |

### 모을 것 (CSV 열)

`기관, 구분, 과정명, 대상, 형태, 기간·시수, 특징·커리큘럼, 출처, 확인수준, 확인일`

- **확인수준**은 반드시 정직하게 적습니다: `원문확인` / `기사인용` / `검색요약`
  - 기관 페이지를 직접 열어 본 것만 `원문확인`
  - 모르는 항목은 비워두지 말고 **`확인 필요`** 라고 적습니다. **추측해서 채우지 마세요**
- 같은 기관·같은 과정이 이미 있으면 새 줄을 만들지 말고 **그 줄을 갱신**하고 `확인일`을 바꿉니다
- 과정이 없어진 게 확인되면 지우지 말고 특징 칸에 `(YYYY-MM-DD 기준 페이지에서 사라짐)`이라고 남깁니다

### 무엇을 보려는 건가

과정 목록 자체보다 **흐름**이 중요합니다. 이런 게 보이면 특징 칸에 적어둡니다.

- 단발 특강 → 직무별 과정 → 인증·레벨 체계로 가는 움직임 (예: 삼성 SKADA 인증)
- "AI 이해" 같은 교양형이 빠지고 "직무별 실습·현업 적용"으로 옮겨가는지
- 시수가 길어지는지 짧아지는지, 온라인/오프라인 비중
- 대상이 전 직원인지, 임원부터인지, 특정 직무인지

### 표 다시 만들기

CSV만 고치고 `python3 news/build_table.py` 를 실행하면 `타사교육과정.html` 이 다시 만들어집니다.
**HTML을 직접 고치지 마세요** — 덮어써집니다.
